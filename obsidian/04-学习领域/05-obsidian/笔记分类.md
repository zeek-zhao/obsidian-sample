## **🔗 实际使用流程**

### **工作流示例：**

```
1. 想法产生 → 01-收集箱/临时想法/
2. 每日整理 → 移动到对应领域
3. 学习内容 → 04-学习领域/文献笔记/
4. 深度思考 → 06-知识构建/永久笔记/
5. 项目相关 → 07-项目中心/
6. 完成内容 → 09-归档/
```

### **搜索示例：**

```obsidian
# 查找所有进行中的项目任务
path:07-项目中心/ tag:#状态/进行中

# 查找本周的工作日志
path:03-工作领域/01-工作日志/ "本周"
```

## **⚙️ 自动化和插件推荐**

### **必备插件：**

1. **Templater** - 自动应用模板
2. **QuickAdd** - 快速添加特定类型笔记
3. **Dataview** - 动态查询和展示
4. **Calendar** - 管理每日笔记
5. **Auto Note Mover** - 自动分类

### **自动化脚本示例：**

```javascript
// 自动移动闪念笔记到永久笔记
// (使用 Templater 脚本)
<%*
const note = tp.file.content;
if (note.includes("#永久")) {
    tp.file.move("/06-知识构建/04-永久笔记/" + tp.file.title);
}
%>
```

## **📊 Dataview 仪表板示例**

创建 `00-系统管理/仪表板.md`：

````markdown
```dataview
TABLE WITHOUT ID
  "📊 **工作统计**" as 分类,
  length(filter(rows.文件, (x) => contains(x.path, "03-工作领域"))) as 数量
WHERE file = this.file

UNION
TABLE WITHOUT ID
  "📚 **学习统计**" as 分类,
  length(filter(rows.文件, (x) => contains(x.path, "04-学习领域"))) as 数量
WHERE file = this.file

UNION
TABLE WITHOUT ID
  "💡 **知识笔记**" as 分类,
  length(filter(rows.文件, (x) => contains(x.path, "06-知识构建"))) as 数量
WHERE file = this.file

FLATTEN file AS 文件
WHERE file.path != this.file.path
```
````

## **🎯 实施建议**

1. **分阶段实施**：
   - 第1周：建立 01-收集箱 和 02-每日笔记
   - 第2周：添加工作或学习领域
   - 第3周：建立知识构建体系
   - 第4周：完善项目中心

2. **保持灵活性**：
   - 可以随时调整文件夹结构
   - 使用标签弥补文件夹的不足
   - 重点是内容，不是完美分类

3. **定期维护**：
   - 每周清空收集箱
   - 每月整理归档
   - 每季度回顾分类体系

这个体系足够全面，你可以根据实际需要**选择性使用**某些部分，不需要一次性全部建立。
