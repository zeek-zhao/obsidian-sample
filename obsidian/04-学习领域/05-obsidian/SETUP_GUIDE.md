# Obsidian Vault 目录结构自动生成脚本使用说明

## 🎯 功能说明

这个脚本会自动创建一个完整的 Obsidian Vault 目录结构，包括：

- 10 大主目录分类（00-系统管理 到 99-模板）
- 100+ 个子目录
- 14+ 个示例/模板文件
- 完整的使用指南文档

## 🚀 使用方法

### 方法一：在当前目录创建

```bash
./setup-vault.sh
```

### 方法二：在指定目录创建

```bash
./setup-vault.sh /path/to/your/vault
```

### 示例

```bash
# 在新目录创建
mkdir my-obsidian-vault
./setup-vault.sh my-obsidian-vault

# 在用户目录创建
./setup-vault.sh ~/Documents/MyVault
```

## 🔧 系统要求

- Linux / macOS / WSL
- Bash shell
- 基本命令：`mkdir`, `cat`, `find`

## 📋 下一步操作

执行脚本后：

1. **用 Obsidian 打开 Vault**

   ```bash
   # 直接打开
   open -a Obsidian /path/to/vault # macOS
   obsidian /path/to/vault         # Linux
   ```

2. **阅读核心文档**
   - 先看 `README.md` 了解整体结构
   - 再看 `00-系统管理/分类体系说明.md`
   - 然后看 `00-系统管理/使用流程指南.md`

3. **开始使用**
   - 从 `01-收集箱/今日收集.md` 开始
   - 配置每日笔记功能
   - 根据需要删除/调整不需要的目录

## 🔍 常见问题

### Q: 目录已存在怎么办？

A: 脚本不会覆盖已有内容，只会创建不存在的目录和文件。

### Q: 可以多次运行脚本吗？

A: 可以，脚本是幂等的，不会重复创建或覆盖。

### Q: 目录太多了怎么办？

A: 根据需要删除不需要的分类，系统会自动适应。

### Q: 可以修改脚本吗？

A: 完全可以！根据自己的需求编辑 `setup-vault.sh`。
