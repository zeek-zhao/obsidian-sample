# 快捷键清单

## 📌 常用快捷键

### 导航

- `Ctrl/Cmd + O` - 快速切换器
- `Ctrl/Cmd + P` - 命令面板
- `Ctrl/Cmd + Shift + F` - 全局搜索

### 编辑

- `Ctrl/Cmd + B` - 加粗
- `Ctrl/Cmd + I` - 斜体
- `Ctrl/Cmd + K` - 插入链接
- `Ctrl/Cmd + E` - 切换编辑/预览

### 其他

- `Ctrl/Cmd + ,` - 设置
- `Ctrl/Cmd + N` - 新建笔记
- `Ctrl/Cmd + Shift + N` - 新建文件夹

## 🔧 自定义快捷键建议

在 设置 → 快捷键 中配置：

- 快速添加到收集箱
- 创建每日笔记
- 插入模板
